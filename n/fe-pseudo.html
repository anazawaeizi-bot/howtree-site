擬似言語の読み方とは

擬似言語は、特定のプログラミング言語に寄らずに処理の手順を書くための、試験用の書き方です。基本情報技術者試験の科目Bは、この書き方でプログラムを示して出題します。読むときに押さえるのは五つです。(1) 代入は「←」で書き、右の値を計算してから左の変数に入れる。(2) if は、上の条件から順に確かめ、最初に当てはまった処理だけを行う。どれにも当てはまらず else もなければ、何もしない。(3) while は、条件が成り立つあいだ処理を繰り返し、毎回、処理の前に条件を確かめる。(4) for は、かっこの中の書き方(例「k を 1 から 3 まで 1 ずつ増やす」)のとおりに変数を変えながら繰り返す。1ずつ減らす書き方や、2ずつ増やす書き方もある。(5) 配列は、同じ型の値を並べたもので、試験の問題文では、ふつう「要素番号は1から始まる」と断ってある。条件の式では、値が等しいことを「＝」、等しくないことを「≠」で書く。x < 6 は x が6より小さい(6は含まない)、x ≦ 6 は x が6以下(6を含む)ことを表し、> と ≧ はその逆向きである。読むときは、変数ごとに欄を作った表に、1行実行するたびに値を書き込んでいくと、取り違えが減ります。

整数型: n ← 4
n ← n × 3　…　右の 4 × 3 を先に計算し、n は12になる
if (n ≧ 10) の中の処理は、n が12なので行う
配列 b ← {7, 1, 6} では、b[1] が7、b[3] が6
for (k を 1 から 3 まで 1 ずつ増やす) は、k が1、2、3 のときに中の処理を行う

宣言の行の「整数型:」は、その変数に整数を入れることを表します。「○」で始まる行は、関数(手続)の名前と、関数が受け取る値(引数)の宣言です。return は、関数の処理を終えて、その値を呼び出し元に返します。返す値を戻り値といいます。「大域:」を付けて宣言した変数は、どの関数からも同じ変数として読み書きできます。mod は割り算の余り(例　7 mod 3 は1)です。
