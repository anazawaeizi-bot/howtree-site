連立方程式とは

二つの文字 x と y を含む方程式を二つ組にしたものを、連立方程式といいます。方程式が一つだけでは x と y の組は一つに決まりませんが、二つの式を同時に成り立たせる組は、ふつう一つに決まります。その組を連立方程式の解といいます。解くときは、二つの式を足したり引いたりして文字を一つ消す加減法か、一方の式をもう一方に代入して文字を一つ消す代入法を使います。

x + y = 5　…①
x − y = 1　…②
①と②を足すと 2x = 6 なので x = 3
①に x = 3 を代入すると 3 + y = 5 なので y = 2

x = 3、y = 2 は、①と②の両方を成り立たせます。
