暗号とディジタル署名とは

暗号は、データを決まった手順で読めない形(暗号文)に変え、鍵を持つ人だけが元に戻せる(復号できる)ようにする仕組みです。共通鍵暗号は、暗号化と復号に同じ鍵を使います。処理は速いのですが、相手ごとに別の鍵を作り、相手に安全に渡す必要があります。公開鍵暗号は、対になる二つの鍵を使います。公開鍵はだれに知られてもよく、秘密鍵は本人だけが持ちます。一方の鍵で暗号化したものは、対になるもう一方の鍵でしか復号できません。だれかに秘密の文を送るときは、受け取る人の公開鍵で暗号化し、受け取る人は自分の秘密鍵で復号します。ディジタル署名は、送った人が本人であることと、途中で書きかえられていないことを確かめる仕組みです。送る人は、文から作ったハッシュ値を自分の秘密鍵で暗号化して署名にし、受け取る人は、送った人の公開鍵で署名を復号して、届いた文から自分で作ったハッシュ値と比べます。ハッシュ値は、文から決まった計算で作る短い値で、文が少しでも変わると、ほぼ確実に違う値になります。

共通鍵暗号で3人(A、B、C)が、二人ずつ別々の鍵を使う：A と B、A と C、B と C の3個
公開鍵暗号で3人：一人に公開鍵と秘密鍵の1組ずつで、3組
機密性(他人に読まれない)を守る：受け取る人の公開鍵で暗号化
本人確認と改ざん検知：送る人の秘密鍵で署名する

Webの暗号化通信(HTTPS)などでは、処理の速い共通鍵暗号で本文を暗号化し、その共通鍵を、公開鍵暗号の仕組みを使って安全に共有する、という組合せが使われます。科目Bの情報セキュリティでは、こうした仕組みを、会社の事例の文章に当てはめて問います。
