微分・積分の考えとは

関数の値の変わり方を調べる「微分」と、その逆の計算である「積分」の基本を学ぶ単元です。関数 f(x) のグラフ上のある点での接線の傾きを、その点での微分係数といいます。x の各値に微分係数を対応させた関数を導関数といい、f′(x) と書きます。導関数の符号から、関数が増えているか減っているかがわかり、最大・最小を調べられます。積分は微分の逆の計算で、グラフと x 軸で囲まれた部分の面積を求めるのに使います。数IIでは、微分は3次まで、積分は2次までの多項式で表される関数を中心に扱います。

f(x) = x² のとき f′(x) = 2x
f(x) = x³ − 3x のとき f′(x) = 3x² − 3
∫ 2x dx = x² + C（C は積分定数）
y = x² と x 軸、直線 x = 3 で囲まれた部分の面積：9

f(x) = x² のグラフの、x = 1 の点での接線の傾きは f′(1) = 2 です。面積の9は、x³/3 に x = 3 を入れた 27/3 = 9 から、x = 0 を入れた 0 を引いて求められます。
