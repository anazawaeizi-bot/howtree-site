平面上の曲線と複素数平面とは

平面上の曲線を式で表す方法と、複素数を平面上の点として表す方法を学ぶ単元です。放物線、楕円、双曲線は、どれも x と y の二次式で表される曲線で、まとめて二次曲線といいます。曲線は、x と y をそれぞれ別の文字 t の式で表す媒介変数表示や、原点からの距離と角で表す極座標でも表せます。複素数 a + bi は、座標平面の点（a, b）に対応させて考えることができ、この平面を複素数平面といいます。複素数のかけ算は、平面上での回転と拡大・縮小に対応します。

楕円：x²/9 + y²/4 = 1（原点を中心に、x 軸方向に ±3、y 軸方向に ±2 まで広がる）
原点を中心とする半径1の円の媒介変数表示：x = cos t、y = sin t
複素数 3 + 4i は点 (3, 4)、絶対値は √(3² + 4²) = 5
i をかけると原点のまわりに反時計回りに90°回転する：(3 + 4i) × i = 3i + 4i² = −4 + 3i

点 (3, 4) を原点のまわりに反時計回りに90°回転すると、点 (−4, 3) になります。
