いろいろな式とは

数Iで学んだ式の計算を広げる単元です。3乗の展開や二項定理、整式を整式で割る計算、分数式を扱います。また、2乗すると −1 になる数 i（虚数単位）を導入し、a + bi の形の数（複素数）まで数の範囲を広げます。これにより、実数の範囲では解がなかった二次方程式も解けるようになります。3次以上の方程式は、因数定理を使って因数分解して解きます。

(a + b)³ = a³ + 3a²b + 3ab² + b³
i² = −1
x² + 1 = 0 の解：x = i、x = −i
x³ − 1 = (x − 1)(x² + x + 1)

x³ − 1 に x = 1 を代入すると0になるので、x − 1 を因数にもちます（因数定理）。
