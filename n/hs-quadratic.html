二次関数の応用とは

二次関数 y = ax² + bx + c は、y = a(x − p)² + q の形に変形（平方完成）すると、グラフの頂点が点（p, q）にある放物線だとわかります。a が正なら頂点で y は最小になり、a が負なら頂点で最大になります。x の範囲が限られているときは、範囲の両端での値と、頂点が範囲の中にあれば頂点での値を比べて、最大と最小を決めます。二次不等式は、グラフが x 軸より上にあるか下にあるかを読み取って解きます。

y = x² − 4x + 3 = (x − 2)² − 1
頂点は点（2, −1）、最小値は −1（x = 2 のとき）
二次不等式：x² − 4x + 3 ＜ 0
　(x − 1)(x − 3) ＜ 0
　1 ＜ x ＜ 3

グラフが x 軸より下にあるのは、x 軸と交わる1と3の間です。
