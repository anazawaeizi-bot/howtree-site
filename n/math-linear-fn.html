一次関数とは

y が x の一次式 y = ax + b で表されるとき、y は x の一次関数であるといいます。a は「傾き」で、x が1増えたときに y がどれだけ増えるかを表します。b は「切片」で、x = 0 のときの y の値です。グラフは直線になり、点（0, b）を通って、右へ1進むごとに上へ a 進みます（a が負のときは、下へ進みます。たとえば a = −4 なら下へ4）。x の増加量に対する y の増加量の割合を「変化の割合」といい、一次関数では傾き a に等しくなります。比例 y = ax は、b = 0 の特別な場合です。

y = 2x + 3
x = 0 のとき y = 3
x = 1 のとき y = 5
x = 2 のとき y = 7

傾きは2、切片は3です。x が1増えるごとに、y は2ずつ増えています。
