積分法とは

数IIの積分を、三角関数、指数関数、分数の形の関数などに広げる単元です。そのままでは積分しにくい関数を、文字を置き換えて積分する置換積分法や、積の形の関数を積分する部分積分法を学びます。定積分を使って、曲線で囲まれた図形の面積、立体の体積、曲線の長さを求めます。

∫ cos x dx = sin x + C
∫ eˣ dx = eˣ + C
∫ 1/x dx = log|x| + C
y = sin x（0 ≦ x ≦ π）と x 軸で囲まれた部分の面積：2

C は積分定数です。面積の2は、−cos x に x = π と x = 0 を入れた差 1 − (−1) から求められます。
