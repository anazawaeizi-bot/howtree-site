物の流れと比率とは

物の流れと比率の問題は、商品などが場所から場所へ流れる様子を、箱と矢印の図で表したものです。箱の文字は、その場所が扱う量を表します。矢印は流れる向きを表し、矢印に添えた文字や数は比率（割合と同じ意味）です。比率は、矢印の出発する箱の量のうち、どれだけが矢印の先に届くかを表します。XからYへの矢印に a と書いてあれば、Yに届く量は a × X で、これを Y = aX と書きます。矢印が続いているときは比率をかけ、二つの矢印が同じ箱に入るときはそれぞれの量を足します。一つの箱から出る比率を全部足しても1より小さいときは、残りは図にかかれていない所へ行くものと考えます。図にかかれていない所から、箱に入ってくる量はありません。

X から Y へ、比率 a で流れる：Y = aX
X から Y へ a、Y から Z へ b で続く：Z = bY = abX
X から Z へ a、Y から Z へ b で集まる：Z = aX + bY
例　X が 200、a が 0.3 のとき、Y に届く量：200 × 0.3 = 60

大文字は量、小文字は比率を表します。対策書や対策サイトでは、この分野は主にペーパーテスティングで出るとされています。対策サイトの例題では、三つの式の正誤を判定して、「アだけ」「アとイ」のような組合せの中から一つを選ぶ形が多く見られます。
